InterpretationArea explains most of the cost: a typical increase in area moves cost by about USD 486k, more than ten times the next factor. Equipment, floors, labor index and material index are significant but small. Weather, risk, complexity and the categorical choices (type, location, construction, foundation) cannot be distinguished from zero in this dataset.

3. Unit cost variance watchlist

Projects whose cost per sq ft is above the IQR screening threshold (USD 194.85 per sq ft): 423 of 6,123 (6.9%). SQL analysis in BigQuery.

InterpretationThe flag is a size effect, not a project type effect: 84% of projects under 2,000 sq ft are flagged and none above 5,000 sq ft. Equipment cost is a near-constant USD 100k, so it weighs 32% of cost on small projects and 7% on large ones. Removing it halves the flagged projects (423 to 205). The rest is unexplained here; other fixed costs such as mobilization or permits are a plausible, untested hypothesis. For small projects, review fixed costs and allow a larger contingency.
Method: multiple regression (OLS), validated against Python statsmodels; outliers by the IQR rule in SQL. Source data: Kaggle "Deep Learning Building Cost Dataset" (CC0). Estimate range assumes roughly normal log errors; heteroscedasticity is present, so treat the range as indicative.
